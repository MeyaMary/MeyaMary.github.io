BinClock

A binary clock visualizer

Content

Syntax: You can use common date formats like HHmmss, YYYYMMDD, Hms, and even 12 hour variants like hmsa. In addition to time formats you can include number literals like 58 or 1234. To make those numbers appear over multiple digits, specify the base like 58@base10. To add padding bits specify the largest value the bits must contain like 58@pad1000. Be warned that if you list a big enough number literal (like > 2 pow 53 - 1) the math breaks.
