Usage

The transform components and their corresponding colors can customized above. The render settings describe the number of chaos games to run and at what resolution.

Note that saving has not been implemented yet.

Render Settings Tips

  • To increase quality I recommend increasing output resolution and chaos games/chaos game steps.
  • If the image is too dim you can increase the gamma or chaos games/chaos game steps.
  • Super sampling is useful to cleanup some noise, although its not as affective as the dynamic density estimation blur used in the paper.
  • Mirror splits as a easy way to make designs symmetric
